# 同一个模块，四种密度

这是协议里最关键的一个机制长什么样。**同一个模块**（一个算统计的函数），AI 按四档密度交接，内容完全不同。

示例用 Python，但机制与语言无关——所有信息都写在注释里。

---

## L3 手把手（默认起步）

```python
# stats.py
# 职责：对已加载的支出记录做统计，供 report.py 渲染表格用。
# 上层谁在用：report.py 的 build_report()

def compute_stats(rows):
    """接收 [{name, amount}] 列表，返回 {count, total, avg, max_name}。
    空列表返回 {'count': 0, 'total': 0, 'avg': 0, 'max_name': None}。
    amount 不是数字时抛 ValueError。"""
    # 手算样例：
    #   输入 [{'name':'早餐','amount':10}, {'name':'打车','amount':30}]
    #   返回 {'count': 2, 'total': 40, 'avg': 20.0, 'max_name': '打车'}
    # TODO 1: 如果 rows 为空，直接返回上面那个空结果，别走后面的计算
    # TODO 2: 把每条记录的 amount 取出来，放进一个列表；顺手校验是不是数字
    #   ⚠️ 黑箱：这里用 isinstance(x, (int, float)) 而不是 try/except，
    #      因为后面还要区分 bool（Python 里 True 是数字），你写完回来问为什么
    # TODO 3: 求 sum / len 得 total 和 avg，注意 avg 可能是小数
    # TODO 4: 找 amount 最大的那条记录，返回它的 name（不是 amount）
    # TODO 5: 组装成字典返回，key 必须和上面四个一致
    pass
```

**你写什么**：把 5 个 TODO 填成代码。**AI 给到什么程度**：连「先判断空」这种顺序都说了。

## L2 给框架

```python
# stats.py
# 职责：对已加载的支出记录做统计，供 report.py 渲染表格用。

def compute_stats(rows):
    """接收 [{name, amount}] 列表，返回 {count, total, avg, max_name}。
    空列表返回 {'count': 0, 'total': 0, 'avg': 0, 'max_name': None}。
    amount 不是数字时抛 ValueError。"""
    # 手算样例：
    #   输入 [{'name':'早餐','amount':10}, {'name':'打车','amount':30}]
    #   返回 {'count': 2, 'total': 40, 'avg': 20.0, 'max_name': '打车'}
    pass
```

**少掉的**：五个 TODO 步骤。

**新增的负担**：你得自己决定「先校验还是先求和」「空列表在哪一步短路」「最大值怎么在不排序的情况下找到」。

这一步是整套协议里最有价值的落差——**从「照着做」到「自己排顺序」，就是分解能力的起点**。

## L1 给签名

```python
# stats.py
# 职责：对已加载的支出记录做统计。

def compute_stats(rows):
    pass
```

**少掉的**：返回结构、边界条件、手算样例。

**新增的负担**：`rows` 长什么样？返回什么？空列表怎么办？amount 是字符串还是数字？——**这些你现在得自己定义，而且定义错了后面全崩。**

这一档最容易卡住，卡住了就升回 L2，不丢人。

## L0 给问题

```python
# stats.py
```

```python
# 这个文件要解决的问题：
# 用户已经有一份支出记录（在 data.csv 里），现在需要算出：
# 一共几笔、总共花了多少、平均每笔多少、最大的一笔是什么。
# 算完之后 report.py 会拿去渲染成表格。
#
# 你需要自己决定：这个文件叫什么、有哪些函数、每个函数接收什么返回什么。
```

**AI 给的**：一段需求描述。

**你做的**：设计整个文件的接口。

这一档跑通了，说明这个项目里「从需求到接口」这段路你自己能走了。

## 递减不是线性的

规则是「每完成 2 个模块降一档」，但实际上：

- 遇到**你不熟的概念**（并发、缓存、权限）→ 主动升一档，别硬撑
- 遇到**你熟但烦的活**（CRUD、表单校验）→ 直接降到 L0，练手不练脑
- 一个项目里，**不同模块可以停在不同档位**——按你在这个领域的熟练度走，不按全局进度

状态文件里每个模块单独记密度，就是为了这个。
