# 迁移是怎么被"设计"出来的

迁移不会自己发生。做完一个项目就自然学会下一个，是幻觉。

这个文件展示协议里最核心的机制：**同一个结构，在项目里故意做两遍。**

---

## 场景：一个记账工具

设计阶段就定下同构对：

```markdown
## 同构对
模块 2（读 CSV）↔ 模块 6（读 JSON）

两个模块的共同结构：
  打开 → 读原始数据 → 校验字段 → 转成统一结构 [{name, amount, date}] → 返回

模块 2 我带你（T1），模块 6 你自己来（T2）。
```

**关键**：这个安排是在项目开始时就写进设计的，不是做到一半临时想起来。

---

## T1：第一次，AI 全带

```python
# loader_csv.py
# 定位：输入是文件路径，输出是 [{name, amount, date}]。系统最外层。
# 职责：读 CSV，校验字段，转成统一结构。

def load_csv(path):
    """空文件返回 []，缺列抛 ValueError。"""
    # 手算样例："name,amount,date\n苹果,10,2026-10-01"
    #          → [{'name': '苹果', 'amount': 10, 'date': '2026-10-01'}]
    # TODO 1: 打开文件，注意编码
    # TODO 2: 读表头，确认三列都在，缺了抛 ValueError
    #   ⚠️ 黑箱：用 csv.DictReader，不手动 split(',')，写完回来问为什么
    # TODO 3: 逐行转成字典，amount 转数字
    # TODO 4: 返回列表
    pass
```

用户写完，Review 通过，收尾时**画模块图**、把"边界条件"记进薄弱点。

**这一遍的目的不是"做完"，是让用户脑子里留下一个可复制的形状。**

---

## T2：第二次，AI 只说一句话

到了模块 6，AI 的全部交接内容就是：

> 这个和 loader_csv 是一个结构。你自己搭。

**没有签名、没有 TODO、没有手算样例。** 只有一个空文件：

```python
# loader_json.py
```

用户要做的事，和 T1 那次一模一样——只是这次没人给步骤：
1. 函数叫什么、收什么、返回什么
2. 怎么读 JSON
3. 怎么校验三个字段
4. 空文件怎么办
5. 字段类型不对怎么办

**这就是迁移的训练场。** 用户在 T1 建立的形状，在这里第一次被独立调用。

如果他卡住了，AI 也不给答案，只问一句：

> loader_csv 里你是怎么处理"缺列"的？

——把记忆的钩子递回去，而不是把答案递过去。

---

## T3：第三次，换个场景但原理相同

后来要加一个功能：从某个 API 拉数据。

AI 不说是同构的，只问：

> 这个和前面两个 loader 是不是一回事？

**用户要自己判断**：是的，都是"取原始数据 → 校验 → 转统一结构"。差别只在"从哪取"。

判断对了，他自己写；判断错了，AI 指出差别在哪，然后降回 T2。

这一档练的是**识别**——能不能在陌生场景里认出熟悉的形状。这才是迁移的真正定义。

---

## T4：新项目，只挑刺

下一个项目，用户说"我想做一个 XX"。

AI 不再给设计，只在用户给出设计后挑刺：

> 你这个把校验放在 loader 里，好处是少一个文件，代价是 loader 没法单独测。你接受吗？

---

## 一张表看清差别

| | AI 给什么 | 用户做什么 | 练的是什么 |
|---|---|---|---|
| **T1** | 设计 + 骨架 + 步骤 | 填代码 | 建立形状 |
| **T2** | 一句"和上次一样" | 复现整个形状 | 调用记忆 |
| **T3** | 一句"是不是一回事" | 判断 + 复现 | 识别形状 |
| **T4** | 只有挑刺 | 从零设计 | 独立 |

**T1 到 T2 的落差最大，也最值钱。** 从"给步骤"到"什么都不给"，中间没有缓冲——但正因为没有缓冲，才能看出形状到底有没有长进去。

---

## 如果项目里没有同构对

大部分项目天然有，只是没被注意到。找法：

1. 有没有两个地方都在"读外部数据"？（文件 / 网络 / 数据库）
2. 有没有两个地方都在"把数据变成人能看的东西"？（表格 / 报告 / 页面）
3. 有没有两个地方都在"校验用户输入"？

都找不到，就**加一个**。最便宜的是"导出"——它通常和"导入"结构对称，而且是个真需求，不是练习题。

**加一个真功能来做迁移训练，比编一个练习题有效得多。** 因为它是系统的一部分，用户能感觉到它在哪、给谁用。
