# 设计依据：证据清单

这份文件记录 `learn-by-building` 每一条规则背后的证据，或者——在找不到证据时——明确标注那是假设。

分级：**强** = 多个随机/准实验且方向一致；**中** = 有对照但样本小或单一情境；**弱** = 相关研究/间接证据；**个案** = 单一小样本或经验之谈。

所有链接均实际打开核对过。

---

## 证据 → 设计映射

先看结论怎么落到协议上：

| 协议里的设计 | 依据 | 强度 |
|---|---|---|
| 密度四档，每 2 个模块降一档 | ①样例效应 + ②脚手架渐撤（范例 → 补全 → 独立） | 强 / 中—强 |
| L3 给编号实现步骤，不直接给成品代码 | ①新手需要完整范例，但不能直接抄成品 | 强 |
| 交接产物带手算样例 | ④先解题后讲解，前提是有明确的正确参照 | 强 |
| Review 必须先问「你最不放心哪一段」 | ③生成效应：自己产出 > 阅读 | 强（边界窄） |
| 黑箱最多 2 个 / 模块，且必须回头解释 | ②跳档会掉效果 | 中—强 |
| 收尾问「这次你写了哪几行」 | ⑩⑬练习期表现 ≠ 学习结果 | 强 / 中 |
| 不写测试脚本，只写手算样例 | ⑫AI 组没更快却学得更少 | 中 |
| 键盘必须在用户手上 | ⑩⑪护栏决定方向，不是模型 | 强 |

## 1. 学习科学基础机制

**① 样例效应 + 专长反转：给新手的和给熟手的应该相反——强。**
新手先看完整范例优于直接解题；同一份范例对已具备图式的人变成冗余负荷，效果反转。这是认知负荷理论里重复验证最多的效应之一。
https://doi.org/10.1207/s15326985ep3801_4

**② 脚手架渐撤（fading）：中—强。**
证据支持的不是「一直给范例」，而是三段式：完整范例 → **补全题**（挖掉部分步骤）→ 独立解题。中间这一档是效应关键，跳过它直接从范例跳到解题会掉效果。
https://doi.org/10.1207/s15326985ep3801_3

**③ 生成效应：强（但边界窄）。**
86 项研究、17,711 人的元分析确认「自己产出 > 阅读现成内容」，但测量几乎都是记忆与近迁移；对「编程远迁移」没有直接证据，别过度外推。
https://doi.org/10.3758/BF03193441

**④ 合意困难的边界：强。**
166 项比较的元分析，Hedges' g = 0.36 [0.20, 0.51]，**先解题后讲解**优于先讲解后解题。边界很明确：失败之后必须有明确讲解与正误对比，否则只是挫败。
https://doi.org/10.3102/00346543211019105

## 2. 编程学习专门研究

**⑤ 子目标标注：中—强。**
265 人、整学期、5 个班的准实验（非随机）：小测 48% vs 41%（d=0.44，p=.001）；不及格率 25% vs 44%，作者结论是「退课与不及格概率减半」。**但期末考试均分 75% vs 72% 不显著（p=.24）**——效应主要落在形成性测验和「人还在不在」，不在期末分。
https://doi.org/10.1186/s40594-020-00222-7

**⑥ Parsons 问题：中，且学界自己认为未定论。**
2022 年还在组织多机构联合研究来确定其效果，说明此前证据以课堂准实验为主。
https://doi.org/10.1145/3502717.3532172

**⑦ PRIMM（Predict-Run-Investigate-Modify-Make）：弱。**
原始论文是社会文化视角的设计研究，质性证据，不是对照实验。理论合理，硬证据缺。
https://doi.org/10.1080/08993408.2019.1608781

Use-Modify-Create 同属框架性主张，没有找到检验其递进顺序的实验。

**⑧ 读代码 vs 写代码：弱（相关，非因果）。**
入门课期末分析发现读/追踪与写强相关，且学生写代码能力普遍低于读代码能力——但这是相关性，**没有实验证明「多读可以替代写」**。
https://doi.org/10.1145/1404520.1404531

「代码阅读能否独立训练」：没找到直接实验。

**⑨ 结对编程：中，但证据在「质量/效率」，不在「学习」。**
元分析层面主要是质量提升与约 15–20% 时间成本。
https://doi.org/10.1109/MS.2007.158

**「新手+专家配对时谁打字学得更多」——没找到对照实验。** 这是本清单里最明显的一个空洞，协议里不要假装有依据。

## 3. AI 辅助与学习效果

**⑩ AI 会降低学习效果：强。**
近千名土耳其高中生 RCT，两个阶段：练习（可用 AI）→ 撤掉 AI 的考试。练习期成绩 +48%（GPT Base）/+127%（GPT Tutor）；**撤掉后 Base 组比从未用过 AI 的对照组低 17%**，Tutor 组损失基本被消除。机制是「当拐杖」，不是「AI 答错」。
https://doi.org/10.1073/pnas.2422633122

**⑪ 哪些设计要素能翻盘：强。**
哈佛物理 194 人交叉 RCT，AI 组后测中位数 4.5 vs 课堂主动学习 3.5，效应 0.63–1.3 SD，且用时更少（中位 49 分钟 vs 60 分钟）。三个可抄的要素：系统提示写死「促进主动学习/管理认知负荷/成长型思维」；**平台层强制按顺序逐小问推进**（作者说纯靠提示做不到）；**预置教师写的分步解答**防幻觉。
https://doi.org/10.1038/s41598-025-97652-6

**⑫ 效率不升、学习反降：中（N=52）。**
学一个新异步库，AI 组测验低 4.15/27（d=0.74，p=.01），**且没有显著提速**；调试题差距最大。六种交互模式里三种保住学习：只问概念、要求「代码+解释」、先让 AI 生成再追问理解。
https://arxiv.org/abs/2601.20245

**⑬ 元认知惰化：中（N=117）。**
四组随机实验，ChatGPT 组作文分提升最多，但**知识获得与迁移无显著差异**，自我调节过程频次与序列显著变浅。
https://doi.org/10.1111/bjet.13544

**⑭ 引导人类导师「多问少答」也有效：中。**
Tutor CoPilot 让人类辅导者更多提问、更少直接给答案，学生掌握度整体提升，**评分最低的辅导者受益最大（+9 个百分点）**。
https://doi.org/10.21203/rs.3.rs-5363154/v1

**⑮ 「AI 生成后人来 review」：只有个案。**
最接近的证据就是 ⑫ 里 n=2 和 n=3 的两个模式，作者只能描述不能检验。**没有找到「review AI 代码 vs 自己写」的对照实验。**

## 4. 可借鉴的现成协议

**Exercism（人类导师制）**：明确不「把更好的解法送出去」，而是描述其他思路、让学员自己实现；答案折叠成可选展开，**是否展开由学员决定**。
https://exercism.org/docs/mentoring/mindset

**Advent of Code**：不提供官方答案；给出成文的「卡住流程」——先跑题面样例 → 自己造能手算验证的测试用例 → 问朋友 → 过几天再来。并对 AI 有明确立场：「派朋友替你去健身房，你觉得你会变强吗？」
https://adventofcode.com/about

**Nand2Tetris**：项目驱动、不发布解答、400+ 学校采用——但官网没写成文禁令，机制是「每章必须交付可运行的门电路/编译器」，靠产物而非规则约束。

**Spec Kit（GitHub 官方）**：constitution → specify → plan → tasks → implement → converge，规则原文是「一次跑一步，每步结果先 review 再继续」。
https://github.com/github/spec-kit

**Claude Code 官方最佳实践**：先让 AI 访谈你、写出 SPEC.md，再开新会话实现；先写失败测试再修；「给它一个能跑的检查」；**要证据——命令和输出，不接受『测试都过了』**；用没见过过程的子代理做 review；同一问题纠正两次就 /clear 重写提示。
https://www.anthropic.com/engineering/claude-code-best-practices

## 只保留 5 条最硬的

1. **验收只看「撤掉 AI 之后」**。三个独立研究一致：练习期表现与学习结果可以背离，撤掉工具后的测验才是唯一可信指标（⑩⑪⑫）。
2. **同一个模型，护栏决定方向**。不给答案 + 预置教师提示 + 逐步引导，能把 −17% 扭成不掉（⑩⑪）。这是整套协议唯一「可复制的因果证据」。
3. **新手先给完整范例，然后撤**。范例 → 补全 → 独立，跳过补全这档会掉效果（①②）。
4. **先让他卡住，卡完必须讲**。先解题后讲解 g=0.36，前提是失败后有明确讲解与对比（④）。
5. **别拿「任务完成」当学会**。AI 组没更快却学得更少（⑫），作文分更高但迁移没差（⑬）——效率类指标在这件事上系统性说谎。

**两个明确的空洞**：新手+专家配对谁打字（⑨）、review AI 代码的学习收益（⑮）。协议里这两处只能标「假设」，不能标「研究支持」。
